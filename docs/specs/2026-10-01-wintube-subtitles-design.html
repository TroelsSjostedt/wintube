Design spec · Stage 11 · Approved 2026-10-01

WinTube Subtitles

A CC picker in the transport bar backed by YouTube's caption tracks, with a persisted language preference, translate-to-English, and automatic captions while muted. Grounded in a live probe of InnerTube (2026-10-01) and mpv's documented subtitle pipeline.

Base WinTube v2.2.0 (stage 10's libmpv player) Data the VISIONOS player response WinTube already fetches

1 · Caption data (Core)

  • StreamService.Pick additionally parses captions.playerCaptionsTracklistRenderer.captionTracks from the same player JSON it already reads: per track baseUrl, languageCode, display name (handle both runs and simpleText shapes), and kind == "asr" (auto-generated). New CaptionTrack(string Url, string Language, string Name, bool IsAutoGenerated); ResolvedStream gains IReadOnlyList<CaptionTrack> Captions (empty when the captions key is absent — that is the no-subtitles signal, not an error). Both ladder rungs (VISIONOS and ANDROID) carry the same tracks.
  • Probe facts honored: the timedtext URLs are pre-signed, need no auth or headers, and are IP-bound with ~7 h expiry — they are consumed at playback time and never persisted. &fmt=vtt yields WebVTT (the format mpv/ffmpeg demuxes); &tlang=en adds server-side translation.
  • Tests: parsing fixtures modeled on the probe dumps (6-track video incl. ASR; both name shapes; absent captions key; URL building with fmt/tlang).

2 · mpv attachment (MpvPlayerHost)

  • The subtitle travels per load via mpv's sub-files option, set before loadfile exactly like user-agent/alang. This sidesteps sub-add's synchronous download and makes reload survival structural: quality switches and ladder retries re-attach the track because PlayerPage passes it into every Load.
  • Load gains string? subtitleUrl; new property SubtitleVisible (mpv sub-visibility). With a single external track per load, selection is implicit (sid auto-selects the only track); switching tracks mid-play reuses the established reload-at-position mechanic from the quality picker.
  • Styling: mpv defaults (white, window-scaled — VTT arrives effectively unstyled, so the sub-* options fully apply if tuning is ever wanted; none shipped now).

3 · CC picker (transport bar)

  • A DropDownButton (glyph E7F0) beside Speed, visible whenever the video has caption tracks — windowed and fullscreen alike. Its flyout joins the auto-hide guard.
  • Menu: Off · one entry per track ("English", "English (auto)", …) · Translate to English (shown only when no English track exists; translates the video's default track via tlang=en).
  • Picking an entry stores the choice and reloads at the current position (same mechanic and no-op rules as the quality picker: picking the active entry does nothing).

4 · Preference + mute automation

StateMeaning
OffNo subtitles (the default).
ManualThe user picked a track/translation. Survives mute/unmute.
AutoMuteEnabled by the mute automation; retired on unmute.
  • Persisted preference: null (off) or a language code, stored in settings.json. Applied per video: manual track in the language → ASR track in the language → (preference "en" and no English track) translation. Picking Off persists Off. PlayerSettingsStore is reworked to read-modify-write a settings record so volume and subtitle preference coexist (known debt — its save currently overwrites the file).
  • Mute automation: muted means volume reaches 0. On mute with state Off → enable the best track as AutoMute (preference chain; lacking a preference, the video's default track). On unmute → AutoMute turns off; Manual stays. A manual pick while muted becomes Manual (survives unmute); a manual Off while muted stays off until the next mute. AutoMute never touches the persisted preference.

5 · Unchanged / out of scope

  • Previews, SponsorBlock, sync, comments, description — untouched. The ANDROID 360p fallback gets subtitles too (same tracks in its player response).
  • Out of scope: subtitle styling settings, secondary subtitles, full translation language menu (only English), srv3/json3 formats, caching caption text.
