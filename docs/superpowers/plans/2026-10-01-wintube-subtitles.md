# WinTube Subtitles Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A CC picker in the transport bar backed by YouTube's caption tracks, with a persisted language preference, translate-to-English, and automatic captions while muted.

**Architecture:** `StreamService` parses `captionTracks` off the player JSON it already fetches into `ResolvedStream.Captions`. The chosen track's `baseUrl&fmt=vtt` URL rides into every `MpvPlayerHost.Load` via mpv's `sub-files` option (structural survival of quality switches and ladder retries). PlayerPage owns a CC `DropDownButton`, the persisted preference, and the Off/Manual/AutoMute state machine; preference selection and the state machine live in Core as pure, tested logic.

**Tech Stack:** WinUI 3 / .NET 8, libmpv (`sub-files` option), xUnit.

**Spec:** `docs/specs/2026-10-01-wintube-subtitles-design.html` — read it first.

## Global Constraints

- Timedtext URLs are pre-signed, need NO auth/headers, are IP-bound with ~7 h expiry: consumed at playback time, never persisted. `&fmt=vtt` for WebVTT; `&tlang=en` for translation.
- Absent `captions` key in the player JSON = no subtitles (empty list), never an error.
- The subtitle attaches per load via mpv option `sub-files` set BEFORE `loadfile` (like `user-agent`/`alang`) — never `sub-add` (synchronous download; dies on loadfile replace).
- Track name parsing must handle both `{"runs":[{"text":...}]}` (VISIONOS) and `{"simpleText":...}` (TVHTML5) shapes; `kind == "asr"` marks auto-generated.
- Preference states: `null` = off (default and persisted-off), else a language code. AutoMute never writes the preference.
- Mute = volume reaching 0. Mute automation: Off→AutoMute(best track) on mute; AutoMute→Off on unmute; Manual survives both; manual pick while muted = Manual; manual Off while muted stays off until next mute.
- Reconcile against CURRENT sources before editing — PlayerPage/MpvPlayerHost have drifted from any line numbers here. Current transport-bar control row columns: 0 PlayPause, 1 Volume, 2 TimeLabel, 3 SkipBlockButton, 4 spacer(*), 5 QualityButtonBar, 6 CommentsButtonBar, 7 SpeedButton, 8 FullScreenButton.

```csharp
/// What the player should attach for a video, given the tracks and the persisted preference.
public static class SubtitleSelection
{
    /// Preference chain: manual track in the language → ASR track in the language →
    /// (preference "en" and no English track) translation of the default track → null.
    /// language match = languageCode equals preference OR starts with preference + "-".
    public static SubtitleChoice? Choose(IReadOnlyList<CaptionTrack> tracks, string? preferredLanguage);
}
/// Kind: Track (Url = the track's VttUrl) or TranslateToEnglish (Url = default track's TranslatedVttUrl("en")).
public sealed record SubtitleChoice(string Url, string Language, string Label, bool IsTranslation);

public enum SubtitleMode { Off, Manual, AutoMute }
/// Pure transition table for the mute automation. The caller owns current mode + muted flag.
public static class SubtitleMuteMachine
{
    /// Returns the new mode when mute state flips. Off+mute→AutoMute (callers attach the best
    /// track); AutoMute+unmute→Off; Manual never changes.
    public static SubtitleMode OnMuteChanged(SubtitleMode current, bool nowMuted);
    /// A manual pick always yields Manual; a manual off always yields Off (even while muted).
    public static SubtitleMode OnManualPick(bool pickedOff);
}
```

- [ ] **Step 1: Failing tests** — cover: Choose prefers manual over ASR for the same language; `en` preference with only `en-US` track matches; preference null → null; "en" preference + no English track + non-empty tracks → translation choice (IsTranslation, Url ends `&tlang=en`, source = first track); empty tracks → null even with preference. Machine: `OnMuteChanged(Off, true) == AutoMute`; `OnMuteChanged(AutoMute, false) == Off`; `OnMuteChanged(Manual, false) == Manual`; `OnMuteChanged(Manual, true) == Manual`; `OnMuteChanged(Off, false) == Off`; `OnMuteChanged(AutoMute, true) == AutoMute`; `OnManualPick(false) == Manual`; `OnManualPick(true) == Off`.
